## 二、经验反思

### 1. Python文件命名陷阱（高频错误）
- **问题**：文件名含空格（如 `test url. py`）会导致 `uv run` 报 "No such file or directory"
- **解决**：所有工作区文件必须用无空格的名字（如 `test_url.py`）
- **操作**：用 `write_ file` 写文件时注意不要在文件名中打空格

### 2. Python脚本中的URL空格（高频错误）
- **问题**：在写Python脚本时，URL字符串 `"https://www. plap. mil. cn/..."` 中手误打进了空格
- **错误**：导致 `requests.get()` 报 `NameResolutionError`（域名解析失败）
- **解决**：写URL字符串时用纯英文，不要有空格
- **正确URL**：`https://www. plap. mil. cn`（但注意我手写时打成了 `www. plap.` 有空格，实际应该是 `www. plap. mil. cn` 无空格）

### 3. 浏览器工具名被系统插空格的Bug
- **问题**：`browser_ use`、`execute_ shell_ command` 等工具调用时，系统在函数名下划线后插入了空格
- **观察**：仅在本轮对话中多次出现，前几轮未出现——可能是本轮上下文污染
- **解决**：直接写正确格式的工具名（不带空格的下划线）
- **备选方案**：用 `execute_ shell_ command` 直接执行 `curl` 命令（curl已内置于Windows）

### 4. CMYK图片处理要点
- PIL的CMYK模式：`img.getpixel()` 返回4元素元组 `(C, M, Y, K)`
- 判断纯白：`pixel == (0, 0, 0, 0)`
- 判断黑色网格线：`pixel[3] > 200`（K值高）
- 判断色块：`pixel[3] < 200 and (pixel[0]>0 or pixel[1]>0 or pixel[2]>0)`

### 5. Excel读取要点
- 用 `openpyxl`（不用pandas，因为要额外安装）
- 正确用法：`openpyxl.load_workbook(path, data_only=True)` 然后 `.iter_rows(values_onnly=True)`
- 文件名含中文路径直接支持
