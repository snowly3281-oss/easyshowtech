# 2026-10-19 / 2026-10-20 — Printing service pages

- Fixed `/printing-services/[slug]` hero image rendering in `src/pages/printing-services/[slug].astro`.
- Switched `.ps-hero img` from `object-fit: cover` to `object-fit: contain`

  This is a placeholder, not a service-specific photo. Image dimensions

## Decisions
- Picked `contain` (not `cover`) so the full picture is visible inside the
  frame. Cover cropped the picture to fill the box and looked broken when
  the source asset has whitespace padding.
